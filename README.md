# ai-education-platform-architecture
Welcome to the architecture repository for the AI Education Platform.

This repository contains the product vision, instructional philosophy, architecture decision records (ADRs), AI agent specifications, educational knowledge model, interaction models, and technical architecture.

It serves as the single source of truth for all product and architectural decisions and is maintained independently from the application source code.
